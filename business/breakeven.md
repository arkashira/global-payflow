# breakeven.md

## Unit Economics & Break-even Analysis for Global Payflow

### Cost per Active User
- **Compute Costs**: $0.10 per user per month
- **Storage Costs**: $0.05 per user per month
- **Bandwidth Costs**: $0.02 per user per month

**Total Cost per Active User**:  
\[ 
\text{Total Cost} = \text{Compute} + \text{Storage} + \text{Bandwidth} = 0.10 + 0.05 + 0.02 = \text{\$0.17} 
\]

### Pricing Tiers
| Tier Name      | Monthly Price (USD) | Features                                                                 |
|----------------|----------------------|--------------------------------------------------------------------------|
| Basic          | $50                  | 1,000 transactions, 24/7 support, basic reporting                       |
| Professional    | $200                 | 10,000 transactions, advanced reporting, fraud detection, priority support |
| Enterprise      | $500                 | Unlimited transactions, custom integrations, dedicated account manager    |

### Customer Acquisition Cost (CAC) Range
- **CAC Estimate**: $150 - $300 per user  
This includes marketing expenses, sales team costs, and onboarding resources.

### Lifetime Value (LTV) Estimate
- **Average Revenue per User (ARPU)**: 
  - Basic: $50/month → $600/year
  - Professional: $200/month → $2,400/year
  - Enterprise: $500/month → $6,000/year

Assuming an average customer retention period of 3 years:
- **LTV Calculation**:
  - Basic: $600 * 3 = $1,800
  - Professional: $2,400 * 3 = $7,200
  - Enterprise: $6,000 * 3 = $18,000

### Break-even Users Count
To calculate the break-even point, we need to cover the fixed costs and the CAC.

Assuming fixed costs of $10,000/month:
- Break-even users for each tier:
  - Basic: 
    \[ 
    \text{Break-even Users} = \frac{\text{Fixed Costs} + \text{CAC}}{\text{Price per User}} = \frac{10,000 + 150}{50} \approx 201 \text{ users} 
    \]
  - Professional:
    \[ 
    \text{Break-even Users} = \frac{10,000 + 150}{200} \approx 51 \text{ users} 
    \]
  - Enterprise:
    \[ 
    \text{Break-even Users} = \frac{10,000 + 150}{500} \approx 20 \text{ users} 
    \]

### Path to $10K MRR
To achieve $10,000 in Monthly Recurring Revenue (MRR):
- **Basic Tier**: 
  \[ 
  \text{Users Required} = \frac{10,000}{50} = 200 \text{ users} 
  \]
- **Professional Tier**: 
  \[ 
  \text{Users Required} = \frac{10,000}{200} = 50 \text{ users} 
  \]
- **Enterprise Tier**: 
  \[ 
  \text{Users Required} = \frac{10,000}{500} = 20 \text{ users} 
  \]

### Summary
- **Total Cost per Active User**: $0.17
- **Pricing Tiers**: Basic ($50), Professional ($200), Enterprise ($500)
- **CAC Range**: $150 - $300
- **LTV Estimates**: Basic ($1,800), Professional ($7,200), Enterprise ($18,000)
- **Break-even Users Count**: Basic (201), Professional (51), Enterprise (20)
- **Path to $10K MRR**: Basic (200 users), Professional (50 users), Enterprise (20 users)
